# Purple Heart Shelf

Purple Heart Shelf is a custom Minecraft plugin that adds a unique decorative block to your Bedrock server. This plugin introduces a custom shelf block with the identifier `starfault:purple_heart_shelf`, designed to function similarly to vanilla Minecraft shelves but with a distinctive purple heart theme. It's perfect for adding a touch of elegance and personalization to your server's world.

## Install

1. Download the plugin JAR file from the releases section of this repository.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock server.
3. Start or restart your server to load the plugin.

## Use

1. After installation, the custom shelf block will be available in your server's creative inventory.
2. Place the shelf block in your world like any other block.
3. Use the shelf block to display items, similar to vanilla shelves.
